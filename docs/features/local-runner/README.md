# Local runner

The developer installs this as a Mac app or a Windows app, opens it like any other application, and runs end-to-end tests that already live in a project. The result is shown in the app's own window.

The project's application is already running. The suite starts from a command-line command. This runner does not start that application.

| Doc | What it covers |
| --- | --- |
| [run-suite.md](run-suite.md) | Choose a project, run its E2E command, watch pass and fail, read a user story when the test has one, and ask an installed agent CLI to create or fix |

Requirements for this behaviour are the user stories in [.docs/stories/](../../.docs/stories/README.md): US-1 through US-8.

Delivery tickets for the first shippable app are [TKT-1](../../.docs/tickets/TKT-1-open-the-app.md) through [TKT-8](../../.docs/tickets/TKT-8-accept-or-discard.md), indexed in [.docs/tickets/](../../.docs/tickets/README.md).
