# US-10: Open Settings from the main app menu

* **User value:** As a developer, I want a main app menu and a Settings page for environment, project path, and suite command, so that the run page stays focused on running and fixing tests.
* **Source:** Request to move Environment, Project, and Command into Settings behind a main app menu
* **Tickets:** [TKT-10](../tickets/TKT-10-open-settings-from-the-menu.md)

## Acceptance criteria

* The window shows a main app menu the developer can open.
* The main app menu includes a Settings item.
* Choosing Settings opens a Settings page that is not the run page.
* The Settings page shows Environment, Project path, and Suite command.
* The run page does not show Environment, Project path, or Suite command controls.
* From Settings, the developer can return to the run page.
* On Settings, the developer can view and retry the loaded environment.
* On Settings, the developer can enter and change the project path and the suite command.
