# US-1: Open the installed app

* **User value:** As a developer, I want to install the runner as a Mac or Windows app and open it in its own window, so that I can work with my end-to-end tests without a browser tab.
* **Source:** [docs/features/local-runner/run-suite.md](../../docs/features/local-runner/run-suite.md) — Install and open
* **Tickets:** [TKT-1](../tickets/TKT-1-open-the-app.md)

## Acceptance criteria

* On a Mac, the developer can install the app and open it from the Dock, Launchpad, or Finder.
* On Windows, the developer can install the app and open it from the Start menu.
* The run is shown in the app's own window.
* Opening the app does not open a browser to show the run.
